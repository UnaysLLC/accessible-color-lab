# Accessible Color Lab

A small web tool for checking text and background color contrast using the WCAG contrast-ratio formula.

## Features

- Hex color inputs and native color pickers
- Live contrast ratio
- AA and AAA results for normal and large text
- Reversible foreground and background colors
- Real preview text
- No dependencies or build step

## Run locally

Open `index.html` in a modern browser.

## Important note

Automated contrast checks cover only one part of accessibility. Test complete interfaces with keyboard navigation, zoom, assistive technology, and real users.
